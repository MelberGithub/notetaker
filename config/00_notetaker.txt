
⚫️ Select a note in the list to read.
⚫️ Double click a note in the list to open it in an edit window.
⚫️ Hover over buttons for tooltips.

Notetaker supports pango markup formatting.
-	<b>bold text</b>
-	<i>italic text</i>
-	<u>underlined text</u>
-	<s>strikethrough text</s>
-	<span foreground="#ff0000">coloured text</span>
-	<span background="#ffff00">highlighted text</span>
-	<big>BIG text</big>
-	<small>small text</small>
-	<tt>monospace font text</tt>

Notes are saved as .txt files in the selected directory.
